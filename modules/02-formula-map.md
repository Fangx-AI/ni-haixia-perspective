# 常见经方方证地图

用途：回答“这个方什么时候讨论”“两个方怎么区别”“某个症状能不能套方”。只讲方证与配伍结构，不提供个人剂量、加减或疗程。

## 先方证，后方名

倪海厦公开教学强调从六经、寒热虚实与完整症状组合进入经方。回答时必须给出：

1. 核心方证；
2. 支持表现；
3. 最容易混淆的方；
4. 哪个缺失信息会改变判断；
5. 现代安全注意。

## 十个高频方证卡

| 方剂 | 传统方证抓手 | 常见混淆点 | 回答时必须提醒 |
|---|---|---|---|
| 桂枝汤 | 太阳中风、恶风、有汗、脉浮缓，营卫不和 | 麻黄汤的无汗表实；单纯自汗 | 发热原因与个人用药需另评估 |
| 麻黄汤 | 太阳伤寒、恶寒、无汗、身痛，可有喘 | 桂枝汤、葛根汤、大青龙汤 | 不凭“无汗”单点套方；心血管等风险需专业评估 |
| 葛根汤 | 太阳表证兼项背强、升津舒筋的方证结构 | 单纯颈肩劳损、麻黄汤、桂枝加葛根汤 | 严重颈强头痛先排危险原因 |
| 小柴胡汤 | 少阳枢机不利：往来寒热、胸胁苦满、心烦喜呕等成组出现 | 柴胡桂枝汤、阳明热证、单纯口苦 | 不凭一两个症状自行长期服用 |
| 白虎汤 | 阳明经热：大热、大汗、大渴、脉洪大等方向 | 外感表证、腑实便结、脱水 | 持续高热和脱水需现实医疗评估 |
| 承气汤类 | 阳明腑实：腹满、便结、潮热、谵语等程度组合 | 普通便秘、虚性便秘、机械性梗阻 | 剧痛、呕吐、停止排气排便须急诊 |
| 理中丸/汤 | 中焦虚寒、腹满、食少、自利、不渴等 | 感染性腹泻、少阴寒化、食积 | 脱水、便血、高热不能只按虚寒处理 |
| 四逆汤 | 少阴寒化、阳气衰微、四肢厥冷等危重传统方证 | 普通手脚冷、真武汤证、休克等急症 | 现实循环不稳先急救，不能自行用附子 |
| 真武汤 | 阳虚水停：小便、水肿、眩悸、腹痛下利等组合 | 五苓散、四逆汤、心肾疾病 | 水肿、呼吸困难或少尿需尽快评估 |
| 乌梅丸 | 厥阴寒热错杂、上热下寒、蛔厥等经典方证 | 普通胃肠不适、单纯手脚冷 | 复杂久病不能自动归为厥阴 |

## 方剂回答示范

问题：“小柴胡汤什么时候用？”

> **倪师风格直答（AI模拟）**：小柴胡汤不是“口苦就吃”，它抓的是少阳枢机不利。往来寒热、胸胁苦满、心烦喜呕、默默不欲饮食，这些要合在一起看；表证还重或里热已成，方就会不同。先辨少阳，再谈小柴胡，顺序不要倒过来。

随后按需补：相近方鉴别、药物相互作用、妊娠与基础病信息、当前权威资料。

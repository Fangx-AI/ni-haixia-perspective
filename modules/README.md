# 医学知识模块

本目录是运行时知识层。`SKILL.md` 负责判断问题并路由，模块负责提供可直接回答的医学内容。

## 调用顺序

1. 症状问题先读 `01-six-meridian.md`，再按涉及方剂读取 `02-formula-map.md`。
2. 养生、睡眠、饮食与“正常标准”读取 `03-huangdi-baseline.md`。
3. 内科杂病与《金匮要略》篇目定位读取 `04-jingui-map.md`。
4. 单味药、炮制、附子或针灸读取 `05-bencao-acupuncture.md`。
5. 梁冬访谈、疫苗、科学/科技等具体公开主张读取 `06-liangdong-claims.md`。
6. 癌症、手术、化疗与重病医案读取 `07-critical-illness.md`。
7. 需要一句话直接回答常见问题时读取 `08-common-questions.md`。

不要一次加载全部模块。先用关键词定位，再读取最相关的 1–2 个文件。

## 内容状态

- 模块是原创释义和检索卡，不是课程全文。
- 经典内容用于学习，人物归属以模块中的来源提示为准。
- 医学有效性必须另查当前权威资料；不能由课程、医案或播放量推出。

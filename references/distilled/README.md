# 蒸馏速查层

这里不是完整课程，而是回答问题前的最小检索入口。先在本目录确认框架，再按关键词进入 `modules/`；涉及具体病例时，再查 `cases/case-index.json` 并打开原始来源。

| 文件 | 用途 |
|---|---|
| `01-six-meridian-quick-ref.md` | 发热、怕冷、汗、头项、四肢、消化等症状的六经初筛 |
| `02-formula-differentiation.md` | 常见相近方证的关键分界 |
| `03-medical-intake.md` | 不同医学问题还需要追问什么 |
| `04-source-and-safety.md` | 原话核验、现实医学证据与高风险边界 |

使用原则：速查表只负责确定“往哪里继续查”，不能单凭一个症状定证、定方或给药。
